会话管家 · Claude / ChatGPT / Gemini　使用说明
=================================================

这是什么
  把你电脑上 Claude（桌面版里的 Code 会话、终端里的 Claude Code）、ChatGPT 桌面版（Codex 任务）
  和 Gemini（CLI，以及从 Google Takeout 导入的网页版）的全部对话记录整理成一个列表：搜索、排序、分组、查看正文，一键回到应用，或在命令行里接着聊。

怎么用
  1. 双击「会话管家-版本号-win-x64.exe」。不用安装，也不用另装 .NET 或别的运行库。
  2. 第一次打开会读一遍本机的对话记录；对话很多时先列出最近的几百条，其余的在后台读完再补上。
     之后窗口开着就会自动保持最新，再打开时只读变过的记录。
     对话内容的搜索索引在后台建立（第一次要几十秒，右下角有进度），期间照常使用；
     建完后用过的内存会还给系统
  3. 如果 Windows 提示「Windows 已保护你的电脑」：点「更多信息」→「仍要运行」。
     这是因为程序没有购买代码签名证书，Windows 不认识它，不是查出了病毒。
  4. 想常用的话，可以把 exe 放到固定的文件夹，再右键 →「发送到」→「桌面快捷方式」。

需要什么
  · Windows 10 或 11（64 位）
  · 本机装过 Claude 桌面版 / Claude Code、ChatGPT 桌面版（Codex）或 Gemini CLI——用过哪个，就列出哪个的记录

隐私与安全
  · 完全在本机运行：不联网，不上传任何内容，没有账号
  · 对 Claude、ChatGPT 和 Gemini CLI 的数据只读：从不修改、从不删除（Gemini 的登录凭据从不打开）
  · 列表只加不减：应用删掉或清理了自己的记录，这条对话照样留在列表里（标「原记录已删」）；会话管家在
    数据目录的 archive 文件夹里给每条记录存了副本，照样能看、能搜。只有你右键「从会话管家删除…」才删
    （副本会占几 GB，和这台电脑上对话记录的总量差不多）
  · 自己的数据（目录索引、对话内容的搜索索引、用量统计、设置和最近的搜索）只写在一个文件夹里：
      有 D 盘时是 D:\ClaudeLauncherData，没有 D 盘时是 %LOCALAPPDATA%\ClaudeSessionLauncher
    程序窗口第二行会显示它的实际位置，点一下就能打开
  · 搜索索引（search-index.sqlite）里有你和助手说过的话的副本，只在本机；不想要时在右上角「⋯」
    菜单取消「搜索对话内容」，索引会被删掉

卸载
  删掉这个 exe 和上面那个数据文件夹即可。
  第一次运行时，Windows 会把程序的运行组件解压到 %TEMP%\.net 里，也可以一并删掉。

几个常用操作
  · 直接打字就是搜索：标题、目录、会话 ID，还有对话内容（你和助手说过的话，两个字起）；
    只靠内容找到的行标「内容 N」（N 条消息提到），右侧写明是哪句话提到的；
    搜索时默认按相关度排序。-词 排除含这个词的会话，"一整句" 按整句找，
    搜索框里的「只搜我说的」只在你自己说过的话里找
  · 点空的搜索框、点框右端的时钟或按 Alt+↓：最近搜过的词，点一下再搜一次；
    不想记下搜过什么，在「⋯」菜单取消「记住搜索历史」（已记下的会一并删掉）
  · 点列标题排序，再点一次反向；「全部时间」可以只看今天、最近 7 / 30 / 90 天
  · 选中一条，右侧底部的「最近对话」显示你最后说的话和最后的回复
  · Enter 打开对话记录，Shift+Enter 直接跳到最新；F1 看全部快捷键
  · Ctrl+O（或右侧「在 Claude 中打开 / 在 ChatGPT 中打开」）直接回到官方应用里的这条对话：
    Claude 切到那条会话，ChatGPT 打开那条 Codex 任务（ChatGPT 没开着时会先把它打开）
  · Claude 续接过的会话在列表里标「续接 N」：更早的对话在另外的记录里（那几行写着「续接前」）。
    选中后右侧「续接」一行可以直接打开续接前的部分；对话记录窗口的标题下面也能前后跳
  · 用 claude --resume 续接出来的会话标「续接」，右侧能打开原会话；续接后一句话没说的副本
    自动并入原会话，不再单独占一行。ChatGPT 里分叉出来的任务标「分叉」，同样能打开原任务；
    它们的内容搜索和「改动的文件」只算续接 / 分叉之后的部分
  · 右键任务栏上的会话管家（固定到任务栏后，不开窗口也行）：置顶和最近的对话点一下就在
    Claude / ChatGPT 里打开；不想让 Windows 记下这些标题，在「⋯」菜单取消「任务栏右键列出最近的对话」
  · 对话记录窗口里：每条消息时间左边的复制按钮，一键复制这一条；复制按钮左边的勾选框可以选中好几条
    （按住 Shift 连选一段），再点底部「复制选中的」或「导出选中的…」；Ctrl+F 查找，F3 逐处跳到下一处；
    「改动的文件」看这条对话改过哪些文件、
    每次改了什么；「导出…」可存成 Markdown，或存成一个网页（图片都在里面，双击就能看）
  · 置顶、改名（F2）、备注、分组、收起，只改本工具自己的列表，都可以 Ctrl+Z 撤销
  · 在任何地方按 Ctrl+Alt+Space 唤出会话管家（这个组合被别的程序占用时会自动换一个，按 F1 看是哪个；
    也可以在「⋯」菜单里改成你自己的组合）
  · Gemini CLI 的会话也在列表里（蓝色「Gemini」）：右侧「gemini --resume」在原来的文件夹里开一个终端接着聊；
    它没有桌面应用，所以没有「在应用中打开」
  · 网页版 Gemini 的对话：右上角「⋯」→「导入 Gemini 网页版（Google Takeout）…」，窗口里一步步写了
    怎么在 Google Takeout 导出（只勾 My Activity 里的 Gemini Apps，JSON 或 HTML 格式都行）；导出好后选中下载的
    压缩包就行。以后再导入新的导出，只补上新增的部分
  · 右上角「⋯」菜单：用量统计（Claude、Codex 与 Gemini 用了多少 token）、关闭窗口时留在托盘、
    任务栏右键列出最近的对话、外观（跟随 Windows / 深色 / 浅色）、搜索对话内容的开关

独立第三方工具，不是 Anthropic 或 OpenAI 的产品。
