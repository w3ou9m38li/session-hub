# 会话管家 0.18.0 · Claude / ChatGPT / Gemini

> **Session Hub** — a read-only Windows manager for the conversation history your AI apps keep on
> this computer: Claude (desktop Code and terminal CLI), ChatGPT Codex and Gemini (CLI, and the
> web app through Google Takeout). One searchable list, a transcript reader, export, token usage,
> and a copy of every record kept even after an app deletes it. Chinese UI. Built with the help of
> ChatGPT, Claude and Gemini.
> **[Download the latest release](../../releases/latest)** · [MIT License](LICENSE)

本项目由 ChatGPT、Claude、Gemini 辅助构建。

独立第三方工具，**不是 Anthropic、OpenAI 或 Google 的产品**。它只做两件事：

1. **一键打开官方应用**：Claude 桌面版、ChatGPT 桌面版（Codex 所在的应用），都不等待任何索引。
2. **把本机两款应用（以及 Gemini）的全部对话记录整理成一个目录**：Claude 的桌面 Code 与终端 CLI
   会话、ChatGPT 的 Codex 任务、Gemini CLI 的终端会话，还有从 Google Takeout 导入的 Gemini 网页版对话，
   同一张表里搜索、分组、归档、查看正文、导出，或用各自的 CLI 接着聊。

**对 Claude、ChatGPT 和 Gemini CLI 的实际数据一律只读。** 会话记录、transcript、rollout、侧边栏分组、归档标记，
本工具只读取、从不写入（导入 Google Takeout 时也只读你选中的导出文件）；它写出的每一个文件都在自己的目录 `D:\ClaudeLauncherData` 里（任务栏跳转列表里的
最近对话由 Windows 自己保存，「⋯」菜单可以关掉）。

**列表只加不减。** 应用清理、删除或挪走了自己的记录，会话管家照样列着这条对话（标「原记录已删」），并且早就在
自己的数据目录里给每条记录存了一份副本，照样能看、能搜、能导出；只有你在会话管家里「从会话管家删除…」才会删。


## 为什么不怕应用更新

| 做法 | 本工具 | 为什么 |
|---|---|---|
| 启动 Claude | 商店版：`shell:AppsFolder\Claude_pzs8sxrjxfjjc!Claude`；独立安装包版：它自己的 `claude.exe`（版本信息里的公司须是 Anthropic） | AUMID 由 Windows 包注册表解析，**不含版本号** |
| 启动 ChatGPT | 优先桌面上的「Codex++（全部任务）」快捷方式；没有时用商店包的 AUMID：依次认 `OpenAI.Codex` 与 `OpenAI.ChatGPT-Desktop`（都须是 OpenAI 的发布者 ID `2p2nqsd0c76g0`），应用 Id 读自包清单（本机为 `OpenAI.Codex_2p2nqsd0c76g0!App`） | 快捷方式是你自己的启动方式，自带"商店版正在运行就拒绝"的保护，不与它打架 |
| 安装路径 | 只记录，从不执行 | `C:\Program Files\WindowsApps\…` 每次更新都变 |
| 程序包 | 不碰 | 不打补丁、不改签名、不镜像 |
| 打开一条对话 | Claude：`claude://claude.ai/epitaxy/local_…`、`claude://resume?session=…`；ChatGPT：`codex://threads/<任务 ID>` | 应用自己的链接，不含版本号和安装路径；交给正在运行的 ChatGPT 时用它此刻的程序路径，现查现用 |
| 私有接口 | 不用 | 不调内部 IPC、不启动 App Server、不复用内部端点 |
| Gemini 网页版 | 只读你选中的 Google Takeout 导出 | 不登录、不联网、不调网页版的接口；导出里的东西复制到数据目录 `gemini-web\` 后再读 |
| 应用数据 | **只读** | Claude 的 `claude-code-sessions` / `projects`，Codex 的 `state_5.sqlite` / `sessions` / `archived_sessions`，Gemini CLI 的 `tmp\*\chats\session-*.json` 与 `.project_root`，全部只读打开；Gemini 同一目录里的登录凭据 `oauth_creds.json` 从不打开 |

## 数据目录

```
D:\ClaudeLauncherData\
├─ catalog.sqlite      会话元数据 + 你的分组、归档、置顶、名字与备注（损坏时自动重建）
├─ search-index.sqlite 对话内容的全文索引：只含你和助手说的话，不含工具输出；关掉内容搜索即删除，可随时重建
├─ gemini-web\         从 Google Takeout 导入的 Gemini 网页版对话（entries.json + 每段对话一份 + 附带的图片）：
│                      不是缓存——导出文件和 Google 那边的旧记录可能都没了，删掉就要重新导入
├─ archive\            每条对话记录文件的副本（copies\，文件夹开了 NTFS 压缩）与清单 archive.sqlite：应用删掉或
│                      清理了原记录时读这里。不是缓存，删掉就丢了应用已经删掉的那些；只随「从会话管家删除」减少
├─ probe-cache.json    每条终端记录读出的标题、目录等（按大小和修改时间核对），下次启动只重读变过的；可随时删除
├─ usage.sqlite        用量统计的账本：从记录里读出的每次调用的 token 数（按天、模型汇总）；可随时删除，打开「用量统计」时重建
├─ export\             会话清单、导出的对话（Markdown / 网页）
├─ memory-drafts\      记忆候选草稿
├─ evidence\           每次同步的来源覆盖快照
├─ diagnostics\        （只有在只读打开 Codex 库被拒时，才会在这里放一份快照副本来读）
└─ settings.json       窗口位置与大小、列宽、筛选、排序、阅读器选项与字号、快捷键、托盘、外观、最近的搜索（损坏或缺失时按默认值启动）
```

解析顺序：环境变量 `CLAUDE_LAUNCHER_DATA_DIR` → `D:\ClaudeLauncherData` → `%LOCALAPPDATA%\ClaudeSessionLauncher`
（D 盘不存在或不可写时的兜底）。指向两款应用数据区、驱动器根、用户主目录根的路径一律拒绝。旧位置的数据
首次启动时自动整体迁移，逐个校验后才删除旧目录。当前数据目录常驻显示在窗口第二行，点击即可打开。

## 来源

| 来源 | 读什么 | 怎么读 |
|---|---|---|
| **Claude 桌面 Code** | `claude-code-sessions\{账号}\{组织}\local_*.json` | 只读 JSON；侧边栏分组读自 Claude 的本地偏好缓存 |
| **Claude 终端 CLI** | `%CLAUDE_CONFIG_DIR%\projects\*\*.jsonl` | 只读文件头（256 KB 预算）取标题与工作目录，大小和修改时间都没变的文件下次不重读；子代理 JSONL 只计数（每 5 分钟重数一次） |
| **Gemini 网页版（导入）** | 你选中的 Google Takeout 导出：zip 里的 `My Activity\Gemini Apps\MyActivity.json` 与同目录的图片 | 只在导入时读一次，提问与回答合并进数据目录 `gemini-web\`（按提问的时间、内容和所在对话去重），每段对话写成一份 Gemini CLI 格式的文档，之后列表、阅读器、内容索引、导出都读这份；没导入过就没有这个来源 |
| **Gemini CLI** | `~\.gemini\tmp\<项目>\chats\session-*.json`；项目文件夹里的 `.project_root` 记着工作目录 | 只读 JSON。每个会话是一份随对话整份重写的文档，所以查看、内容索引、用量都整份读（不按偏移续读），大小和修改时间都没变的文件下次不重读；正写到一半、读不了的文件这次不算，下次同步再试，期间不删任何行。只在本机有这个文件夹时才出现这个来源 |
| **Codex（ChatGPT）** | `%CODEX_HOME%\state_5.sqlite` 的 `threads` 表 + `sessions\` / `archived_sessions\` 里的 rollout 文件（也认被压缩成 `.jsonl.zst` 的，读时解压进副本） | SQLite **只读模式**打开；rollout 只按文件名建索引，数据库里没有的才读 64 KB 文件头。子任务（`thread_source=subagent` 或 spawn 来源）只计数不列出；Codex 的侧边栏分区（`thread_sections`）作为它自己的分组显示 |

`CODEX_HOME` 依次取进程环境变量、用户环境变量、`~\.codex`。数据库里记的 rollout 路径找不到时，按任务 ID
在两个目录里找；`\\?\` 前缀会去掉再显示。

## 界面

```
┌ 打开 Claude │ 打开 ChatGPT │ 🔍 搜索标题、目录、ID 或对话内容          │ ⟳ 同步 │        ⋯ ┐
├ [活跃 314 │ 本工具归档 3] [全部应用 ▾] [全部分组 ▾] [全部时间 ▾] 排序 [最后活动 ▾] ↓ 版本 ┤
├──────────────── 会话列表 ─────────────────┬──────────── 选中的会话 ─────────────┤
│ 标题 │ 分组 │ 来源 │ 工作目录 │ 最后活动 │ 大小 │ 应用内 │ 完整标题、来源、工作目录、时间、  │
│ 置顶                                   1 条 │ 分组、记录文件、会话 ID（可选中复制）   │
│ 今天                                   6 条 │                                         │
│ …                                          │ 重命名… 置顶 备注… 生成记忆候选草稿…    │
│                                            │ [查看对话记录]                          │
│                                            │ [在应用中打开] [命令行继续]             │
│                                            │ 整理：[设为分组][移出分组]              │
│                                            │       [收起到归档][按目录自动分组]      │
│                                            │ 最近对话                     看最新 →   │
│                                            │ ┃ 你　　 继续，把测试补全               │
│                                            │ ┃ Claude 测试都过了，下一步……           │
│ 已显示 100 / 共 314 条 · 滚动到底部自动加载 │ ▸ 来源覆盖　3 个来源均已完整读取        │
├ ✓ 已把 2 条收起到本工具归档　撤销                                    上次同步 12:30 ┤
```

- **列表**：标题一栏占满剩余宽度，被截断时悬停显示全文；工作目录按列宽自动缩写成「…\上级\目录名」，
  保留最能区分的末尾；最后活动显示「刚刚 / 3 分钟前 / 昨天 21:40 / 周五 10:00」，悬停看精确到秒的时间，
  每分钟自动刷新；来源按应用着色（Claude 橙、ChatGPT 绿）；标题前的 ⚠ 表示这一行读取不完整。滚到底部
  自动加载下一页，后台同步或整理之后列表保留已加载的页数、滚动位置和选中项；什么都没变时列表不闪。
- **自己保持最新**：切回本窗口时（距上次同步超过 15 秒）、以及窗口开着时每分钟，后台安静地同步一次：不转
  图标、不改状态栏（状态栏里的「撤销」等链接不会被冲掉）、失败也不打扰；没有变化就不碰列表；有变化时，
  若你正在移动鼠标、点击、滚动、打字，会等你停下 1.5 秒再刷新；开着右键菜单或下拉框时一直等到它关上，
  菜单里点的命令不会落到换了位置的另一行上。行不会在指针下面突然换位；选中的那一条和右侧面板（含「最近
  对话」）在刷新时原样保持，不会闪一下「未选择会话」。窗口最小化时不检查，恢复时立刻补一次。后台同步
  进行中按 `F5`：它会接着把结果报出来，若按键时它已经读完一遍，就再读一遍，给出的结果不会早于你按键的时刻。
- **排序**：点列标题按这一列排序，再点一次反向；当前排序的列标题变蓝并带箭头，工具栏的「排序」下拉框和
  方向按钮与它同步，选择会被记住。标题按"读起来的顺序"排（中文按拼音，大小写、全半角不敏感）；未分组、
  没有工作目录、没有时间的行无论正反向都排在最后；同一类里再按最后活动从新到旧。排序由目录数据库完成，
  所以滚到底部加载的后续页也严格按同一顺序，不会漏行或重复。
- **分段**：默认按最后活动排序时按日期分段（今天 / 昨天 / 7 天内 / 30 天内 / 更早），按分组、来源、工作目录、
  应用内状态或大小排序时按类别分段；段标题写明类别和**整个视图里**这一类的条数（不只是已加载的部分），例如
  「Claude · 终端 CLI　140 条」。过了午夜，「今天」自动变成「昨天」。
- **时间筛选**：工具栏「全部时间」可换成今天、最近 7 / 30 / 90 天；搜索和其他筛选在这个范围里进行，会被记住。
- **置顶、改名、备注**（右键菜单或详情面板）：置顶的会话无论怎么排序都在最前，单独成「置顶」一段；改名
  （`F2`）只改本工具里显示的名字，详情里仍写着原标题；备注最多 2000 字，列表里有个小标记，悬停可看。三者都
  参与搜索、都可以撤销，Claude / ChatGPT 里什么都不变。
- **一个对话一行**：Claude 桌面 Code 会话背后就是一份终端记录，以前列成两行，现在合成桌面那一行（最后活动
  取两者较晚的，搜索两边的标题都算）；以前在终端那一行上设过的名字、备注、置顶、分组会移到合并后的一行上。
- **搜索**：同时匹配标题、你起的名字和备注、工作目录、会话 ID（6 位以上的十六进制片段），以及**对话内容**
  ——你和助手说过的话，不含工具输出和系统提示，两个字起。多个词用空格隔开时每个词都要出现，可以一个在标题
  里、一个在内容里，例如 `wheat 病级`；大小写、全半角不敏感，`%` `_` 按字面处理。只靠内容找到的行在标题后
  标「内容」，选中后右侧「对话里提到「…」」列出提到它的地方（谁说的、什么时候、前后文，关键词标色），
  「在记录中查找 →」或回车打开对话记录，查找框已填好并跳到第一处。焦点在列表上时直接打字就会开始搜索。
  没有结果时列表中央会说明原因，并给出「清除搜索 / 显示全部 / 立即同步」之类的下一步。
- **搜索写法与排序**：`-词` 排除（`gwas -kasp` = 含 gwas 但不含 kasp；只写 `-kasp` 则列出其余全部），`"kasp primer"`
  或 `“候选 基因”` 把引号里的内容当一整句找。搜索时排序默认是「相关度」：分「标题、名字或目录里有」和「对话
  内容里提到」两段，后一段按提到的消息条数从多到少，行尾「内容 N」就是这个条数；也可以照常点列标题换排序，
  搜索的排序和平时的排序各记各的。搜索框右侧的「只搜我说的」让对话内容只算你说过的话（标题、目录、ID、名字
  和备注照常搜），行尾的条数和右侧的片段也随之只算你的。
- **最近的搜索**：点空的搜索框、点框右端的时钟或按 `Alt+↓`，列出最近搜过的 12 个词，选一个再搜一次；
  一个词在框里停 2 秒或离开搜索框才算搜过。「⋯」菜单里的「记住搜索历史」可以关掉，关掉即删除已记下的。
- **内容索引**在后台维护：每次同步之后检查一遍，只读有变化的记录——变长的接着上次的位置读，被改写的重读，
  消失的移出索引。第一次建立时状态栏右侧显示「正在建立对话内容索引 n/N」，这时搜索会随着索引陆续补全。
  索引在数据目录的 `search-index.sqlite` 里，只含两边说的话；删掉它不影响任何东西，会自动重建。
- **大小**：列表的「大小」列是记录文件的大小（多半是工具输出），悬停看精确字节数；点列标题按大小排序、分段；
  详情里「记录文件」一行可「在文件夹中显示」（右键菜单同样有），只选中，不移动不删除。
- **右侧面板跟着选中项走**：没选时给出操作提示；选中一条显示它的完整信息，工作目录可「打开 / 复制」，
  会话 ID 可「复制」（悬停看完整 ID）；多选时显示按来源的数量。每个按钮只在能作用于当前选择时可用，不可用时
  悬停说明原因。
- **最近对话**：面板底部显示这条会话里**你最后说的话**和**助手最后的回复**（各最多三行，悬停看更多），
  同名的几条会话由此一眼分清；「看最新 →」打开对话记录并直接跳到结尾。只从文件末尾往前读（先 128 KB，
  不够再放宽），几百 MB 的记录也只读几百 KB；用方向键快速划过列表时只读你停下的那一条，读过的在文件
  没变之前不重读。
- **整理可以撤销**：设为分组、移出分组、按目录自动分组、收起 / 恢复之后，状态栏会出现「撤销」，
  `Ctrl+Z` 同样有效（一步）。撤销只还原这次操作改动过、且之后没被再改动的会话。收起一条之后选中会自动
  落到顶替它位置的那一行，用键盘可以连续整理。
- **状态栏**：进行中 / 成功 / 警告 / 错误各有颜色和图标；需要下一步的消息带链接（撤销、打开草稿、打开文件夹）。
- **来源覆盖报告**折叠成一行结论，展开是与以前相同的完整报告；展开状态会被记住。
- **记住你的设置**：窗口位置与大小（显示器被拔掉时回到主屏居中）、拖动过的列宽、应用筛选、排序、阅读器
  选项与字号。
- **外观**：深色、浅色两套配色，标题栏、滚动条、菜单、提示框、对话框与阅读器统一换；默认跟随 Windows
  「选择你的应用模式」，也可在「⋯」菜单固定。外观在启动时决定，改了之后状态栏提供「立即重新打开」（列表和
  设置都保留）；Windows 自己换了模式时同样会提示。全部按钮都有无障碍名称。
- **全局快捷键与托盘**：在任何地方按快捷键唤出会话管家（光标在搜索框里，可以直接打字），它已在最前面时再按
  一次收起。默认 `Ctrl+Alt+Space`；被别的程序占用时自动改用 `Alt+Shift+Space`，再不行用 `Ctrl+Alt+K`，
  「⋯」菜单和 `F1` 写明当前用的是哪个，也可以在那里关掉。勾选「关闭窗口时留在托盘」后，关窗只是收到右下角，
  点托盘图标或按快捷键回来，右键图标可以同步或退出；注销、关机时照常退出。默认不勾选：关窗即退出。
- 再次启动本程序会把**主列表窗口**恢复并切到前台——即使它被最小化、收在托盘里、前面开着对话记录窗口。

### 兼容性

- **多显示器、不同缩放**：按每显示器 DPI（PerMonitorV2）渲染，窗口拖到另一块缩放不同的屏幕上依然清晰；
  声明了 Windows 10 / 11 兼容与长路径支持。
- **小屏幕**：最小 880 × 540；窗口宽度不足 1120 时右侧面板自动收窄；恢复窗口位置时会限制在当前屏幕内。
- **触摸**：列表与阅读器支持手指拖动滚动。
- **减少动画**：Windows 设置里关掉"显示动画"后，同步中的旋转图标改为静止。
- **读屏软件**：状态栏的结果（同步完成、已撤销……）会作为实时区域播报。
- **数据目录各自单实例**：用 `CLAUDE_LAUNCHER_DATA_DIR` 指向另一个目录时，可以和日常使用的实例同时运行
  （各自的目录数据库互不相干），标题栏会显示「（独立数据目录 …）」；这个目录被拒绝或不可写而退回默认目录时，
  标题栏如实写「未生效」。默认目录仍然只允许一个实例。这样的副本不注册全局快捷键，免得抢走日常那一份的。
- **Claude 的两种装法**：微软商店（MSIX）版照旧按包身份找；没有商店版时，找独立安装包装在
  `%LOCALAPPDATA%\AnthropicClaude` 的版本（先找它的启动器，再找最新的 `app-*`），或 `claude://` 注册指向
  WindowsApps 之外的程序——都要求程序版本信息里的公司是 Anthropic，配置目录取 `%APPDATA%\Claude`。商店版
  若把配置直接写在 `%APPDATA%\Claude`（不经 MSIX 重定向），同样读得到。
- **ChatGPT 的包名**：依次认 `OpenAI.Codex` 与 `OpenAI.ChatGPT-Desktop`，都必须是 OpenAI 的发布者 ID；启动用的
  应用 Id 从包清单读，不写死。
- **搜狗拼音**：装了搜狗拼音（实测 16.6）时，偶尔会遇到窗口每 10 秒顿一下（0.1–0.6 秒）。这是搜狗放在本程序
  界面线程上的定时器：平时每次不到 3 ms，个别时候它会改成每次把系统里的输入法（语言配置、组件注册）挨个查
  一遍；装了搜狗的其他程序里也一样，本程序避免不了。遇到时把会话管家关掉再开一次，通常就好了。

### 正文阅读器

同一个阅读器读两种格式：Claude Code 的 `{type:user|assistant, message:{content}}`，和 Codex 的
`{type:response_item|event_msg, payload}` rollout 信封。

- 你和助手的发言是对话气泡（你的在右侧缩进），文字可以选中复制；工具调用、工具输出、系统提示各折成
  一行，点箭头展开参数与输出（每条最多 16,000 字，超出明确标注截断）。
- **助手的回复按 Markdown 显示**：标题、粗体 / 斜体 / 删除线、行内代码与代码块（保留缩进）、有序 / 无序 /
  嵌套列表、任务列表（☑ / ☐）、表格（对齐方式照写，列宽按内容分配）、引用、分隔线；网页链接可点（在浏览器
  里打开），指向文件的链接只显示、悬停看路径。你的话按原样显示，不做任何解释。几万条真实回复实测解析无异常，
  含大量星号的日志也不会变慢。
- **你发的截图**显示为缩略图（在后台解码，不放大），点一下看原图，右键可复制或另存为；单张超过 12 MB、或
  一次读取累计超过 256 MB 的只写明大小不显示；网络图片只写出链接，从不下载。导出、复制和记忆草稿不带图片数据。
- **不是你说的，不算你的**：Claude Code 以"用户消息"身份写进记录、但标了 `isMeta` / `isCompactSummary`
  的内容——技能的整份说明、斜杠命令的展开、图片尺寸说明、自动发送的"继续"、上下文压缩摘要——折成一行
  「系统」，并写明是什么：「技能说明 · docx」「命令输出 · Set model to …」「上下文压缩摘要」「系统提醒」等。
  这些内容也不会被当作会话标题或记忆候选。
- **你输入的斜杠命令照常显示**：`/loop 每天检查一次`、`/superpowers 还有哪些可以优化` 这类记录外面包着
  Claude Code 的标记，以前整条被折叠；现在显示为你的发言，可以查找。会话没有标题记录时，标题取命令后面
  的内容（`/model`、`/compact` 这类设置命令除外）。
- **窗口独立**：对话记录窗口不属于主窗口——主窗口最小化时它照常显示，任务栏上各有按钮；同时开多条时
  依次错开，不会叠在同一位置；关闭主窗口会一并关闭它们。
- **字号**：`Ctrl + 滚轮`、`Ctrl + +` / `Ctrl + -` 缩放正文，`Ctrl + 0` 还原；会被记住。
- **只看对话**：隐藏工具与系统提示，只留两边说的话；**展开工具内容**：一次展开全部工具详情。两项选择会被记住。
- **查找**（`Ctrl+F`）：查找显示出来的文字，勾选「展开工具内容」后也查找工具参数与输出；`Enter` / `F3`
  下一处、`Shift+F3` 上一处。命中的词在文中标色，当前这一条加框；一条长回复里提到好几次时，`F3` 先走完这一条
  里的每一处再到下一条（往回走时从上一条的最后一处开始），当前这一处用亮橙底深色字单独标出，计数写成
  「3 / 120 条　本条 2/9 处」；每一处都停在窗口上部三分之一处，前后的上下文都在屏幕上；到已加载部分的最后
  一处会自动往后读，不会把"没读到"说成"没有"。
- **开头 / 最新**（`Ctrl+Home` / `Ctrl+End`）：「最新」跳到最后一条。超过 8 MB 的记录先从文件末尾直接读出
  最后约 150 条显示（顶部写着「先显示最后的内容 · 正在载入整段对话…」），整段在后台读完后原地替换，位置不跳；
  小记录直接整段读。滚到底时会等最后几条排好版再贴底，不会差一截。
- **复制一条**：每个气泡时间左边的复制按钮复制这一条的全文（Markdown 原文）；选中文字后 `Ctrl+C` 复制选中的部分。
- **选中几条**：复制按钮左边的勾选框选中这一条（Shift 连选一段），底部的「复制选中的 N 条」「导出选中的…」只处理选中的发言，
  按对话里的顺序；Esc 取消选择。
- **复制全部对话 / 导出…**处理的是**整条对话**，不只是已加载到屏幕上的部分。导出可选 Markdown、文本或
  **网页**：网页是一个自包含的 HTML 文件——助手的 Markdown 按阅读器的样子排版，你的话按原样，截图直接放在
  文件里（一页最多 150 MB，再多的只写名字），工具调用一行一条（勾选「展开工具内容」时可以点开）；内容安全
  策略禁止加载任何外部资源，页面不含脚本，文字全部转义，只有 http / https / mailto 会成为链接。会记住上次选的
  格式，导出网页后状态栏可以直接「打开」。
- **改动的文件**：底部按钮打开一个窗口，左边是这条对话用 Edit、Write、MultiEdit、NotebookEdit 或 apply_patch
  改过的文件（连同它的子代理、Codex 子任务，工具名后标出；可筛选，标出新建 / 已删除 / 已移动、共 +增 −删、改了几次），右边按时间列出这个文件的每一次改动：
  Claude 用它自己记下的带行号补丁，Codex 用实际应用的 unified diff（没有时解析补丁文本，相对路径按当时的
  工作目录补全）；工具报告失败的尝试半透明显示；可「复制改动」为 diff 或「在文件夹中显示」。只读对话记录，
  显示的是当时的改动；用命令行或脚本改的文件不在其中。423 MB 的记录约 0.7 秒读完。
- 读取在后台进行，窗口始终可操作；翻页从上一页停下的位置接着读，几百 MB 的记录读完一遍就是一遍，
  不再每页从头扫描；应用还在写入的最后一行会等它写完再显示。
- 滚动按像素进行，几屏长的回复不会被滚轮一格跳过；滚到底部自动继续加载。
- Codex 把大多数发言写两遍（一次 `event_msg`，一次 `response_item`）：按内容哈希配对，只显示一次，
  真正重复发的同一句话不会被误合并。
- 终端控制序列（ANSI / OSC）会被去掉；正文永远是数据，不执行、不加载远程媒体。工具输出在表情中间被截断时，
  记录里会留下半个表情（孤立的 `\ud83d`）：那半个字符显示为 �，整条消息和整份记录照常读取。
- 工具输出单行超过 4 MB 直接跳过、不读进内存；你和助手的消息（比如带截图的提问）放宽到 32 MB，免得连文字一起
  丢掉。一条消息超过 10 万字时只排版前 10 万字并注明（排版几百万字会让窗口卡住），「复制全部对话」「导出」含全文。
- 「最新」还在后台读取时就开始查找：查找会等这次读取读完再下结论，不会把"还没读到"说成"没有"；查到的位置
  不会被读完后的「跳到结尾」冲掉。同一条会话再次打开会切到已开的窗口；`Esc` 关闭。
- 项目搬过目录或换过盘时，Claude Code 会在新旧两个项目文件夹里各留一份同 ID 的记录；目录和阅读器都取
  **最后写入的那一份**（也是 `claude --resume` 在新目录里接着用的那一份），不会打开过期的旧副本。

### 分组

分组是**本工具自己的标签**：设为分组、移出分组、按工作目录自动分组，以及工具栏的分组筛选。没有本工具
分组时，应用自己的分组会透出来（Claude 的侧边栏分组、Codex 的侧边栏分区），列表里显示为**蓝色**；本工具
的分组是白色，未分组是灰色的「—」。「设为分组」对话框里打字会筛选已有分组，并提前说明回车后是放入已有
分组还是新建——新名字和已有分组只差大小写或全半角时会警告，避免出现两个看起来一样的分组。

## 无界面模式

```
ClaudeLauncher.App.exe --export            # 同步后导出会话清单到 export\
ClaudeLauncher.App.exe --draft all         # 全部记忆候选草稿
ClaudeLauncher.App.exe --draft <会话id前缀>
```

`--open` / `--launch` 不开窗口、不经单实例、不读目录：ID 按链接本身的格式校验，打开后即退出；打不开时弹出本工具的
